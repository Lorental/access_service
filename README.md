# access_service

## Развертывание
1. Скопировать папку с проектом.
2. Создать файл .env из env_example.txt и заполнить его необходимыми данными.
3. Запустить файл докер компоуза.
4. Провалиться в контейнер с сервисом (Access_service), перейти в папку access_service и создать необходимых пользователей с помощью команды python manage.py createsuperuser
5. Готово к использованию.

## Развертывание вне контейнера
1. Скопировать папку access_service.
2. Завести папку .venv через исполнение команды python -m venv .venv
3. Запустить виртуальное окружение через исполнение команды source .venv/bin/activate
4. Установить необходимые пакеты через pip install -r requirements.txt
5. Запустить приложение посредством python manage.py runserver
6. Создать необходимых пользователей через команду python manage.py createsuperuser
